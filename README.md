# Estúdio do Robô

Jogo educativo de Educomunicação para o Ciclo de Alfabetização (1º, 2º e 3º ano),
do Território do Saber "Comunicação e Novas Linguagens" (Programa São Paulo Integral).

- Abra o `index.html` (ou o endereço do GitHub Pages) no navegador. Não precisa instalar nada.
- Os textos, perguntas e notícias fictícias ficam em `js/conteudo.js`, com explicações para editar.
- Tudo é salvo só no navegador de cada computador. O jogo não usa câmera, microfone nem internet depois de carregado.
